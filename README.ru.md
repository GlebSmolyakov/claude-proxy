# claude-proxy

[English](README.md) · Русский

ACP-агент, который запускает Claude Code внутри редактора. Редактор поднимает его
как программу и общается с ним по [Agent Client Protocol](https://agentclientprotocol.com),
а он ведёт Claude Code через [Claude Agent SDK](https://github.com/anthropics/claude-agent-sdk-typescript).
Агент работает собой: со своим системным промптом, инструментами, настройками,
`CLAUDE.md`, скиллами и сабагентами. Редактор показывает, что он делает, и отвечает
на то, о чём он спрашивает.

> [!WARNING]
> Ходы оплачивает тариф, под которым залогинен местный Claude Code. Anthropic
> [не разрешает](https://code.claude.com/docs/en/agent-sdk/overview) сторонним
> продуктам без её одобрения пользоваться входом через claude.ai и лимитами
> подписки, поэтому редактор, работающий через этот хост на тарифе Pro или Max,
> ставит аккаунт под риск.

## Что нужно

Claude Code, залогиненный в ваш аккаунт, и Node 22 или новее. Хост запускает тот
бинарник Claude Code, который приходит вместе с SDK; на другой его переключает
`CLAUDE_CODE_EXECUTABLE`.

```bash
git clone https://github.com/GlebSmolyakov/claude-proxy.git
cd claude-proxy
pnpm install
pnpm run build
```

## Подключить к редактору

В JetBrains Air: _панель задачи > выбор агента > Add ACP Agent_. Air откроет
`acp.json`, на macOS это `~/Library/Application Support/JetBrains/Air/acp.json`.
У Zed то же самое лежит в `settings.json` под ключом `agent_servers`.

```json
{
  "agent_servers": {
    "Claude Code": {
      "command": "node",
      "args": ["/путь/к/claude-proxy/dist/index.js"]
    }
  }
}
```

После сохранения агент появляется в списке и работает в открытом проекте.

## Параметры

| Параметр            | По умолчанию           | Что задаёт                                                                           |
| ------------------- | ---------------------- | ------------------------------------------------------------------------------------ |
| `--permission-mode` | `default`              | Режим новых сессий: `default`, `acceptEdits`, `plan`, `dontAsk`, `bypassPermissions` |
| `--model`           | модель из настроек CLI | Модель всех сессий: алиас или полный id                                              |
| `--idle-minutes`    | `30`                   | Через сколько остановить агента, которым не пользуются; `0` оставляет его жить       |
| `--login`           |                        | Отдать терминал входу Claude Code                                                    |
| `LOG_LEVEL`         | `info`                 | С `debug` в лог попадает stderr CLI; логи идут в stderr, в stdout живёт протокол     |

## Что видит редактор

|                          |                                                                                                    |
| ------------------------ | -------------------------------------------------------------------------------------------------- |
| Ответ                    | текст и размышления по мере набора                                                                 |
| Каждый вызов инструмента | карточка с заголовком, диффом правки, результатом и планом, который ведёт агент                    |
| Токены                   | сколько занято в контексте и во что обошёлся ход                                                   |
| Разрешения               | диалог на действие и режимы, между которыми переключается сессия                                   |
| Вопросы                  | свои и от MCP-серверов, формой                                                                     |
| Файлы                    | читаются и пишутся через буферы редактора, так что несохранённые правки учитываются                |
| Команды                  | идут в терминал, который открывает редактор, и видны по ходу                                       |
| Сессии                   | возвращаются через `session/load`, закрываются через `session/close` и останавливаются при простое |
| Настройки                | модель, уровень усилий, размышления и слэш-команды CLI                                             |

Чего редактор не умеет, то остаётся за агентом: файлы идут на диск, команды
выполняются молча, вопросы не задаются.
